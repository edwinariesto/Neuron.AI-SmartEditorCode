# Neuron.AI — Standalone Interactive Code Editor & AI Debugger
> Proyek Mandiri: **editorcode.ai**  
> Lokasi: `neuron.ai/editorcode.ai`

## Fitur Utama
1. **Deteksi Otomatis Bahasa Real-time:**
   - Mendeteksi PHP, Python, JavaScript, TypeScript, MATLAB, Java, HTML/SVG, SQL, C/C++, C#, Ruby, JSON secara cerdas tanpa bergantung pilihan manual.
2. **AI Runtime Simulation (Dukungan Segala Bahasa):**
   - Menjalankan berbagai bahasa (termasuk MATLAB, Java, C++) dengan simulasi AI online presisi tinggi ketika API Key terhubung.
   - Diagnostik lokal cerdas untuk kode MATLAB dan bahasa lainnya ketika API key belum terpasang.
3. **Multi-Model AI Provider:**
   - Konfigurasi mandiri untuk Google Gemini (2.5 Flash, 1.5 Pro), OpenAI ChatGPT (GPT-4o, GPT-4o Mini), Anthropic Claude (3.5 Sonnet), dan DeepSeek.
   - Textbox paste instan dari clipboard dan pengamanan key di `localStorage`.
4. **Line-by-Line AI Debugger & Audit:**
   - Deteksi kesalahan sintaks dan logika baris per baris dengan anotasi langsung pada editor Ace.
   - Rekomendasi perbaikan dalam bahasa awam dengan tombol salin solusi 1-klik.
5. **Multi-Dimensional Visualizer & Device Mockup:**
   - Pratinjau live Web HTML, Grafis SVG, Citra/Gambar Base64, Tabel Data Interaktif, Visual 2D Canvas matematika, dan 3D WebGL (Three.js).
   - Mode ilustrasi perangkat responsif: **Desktop (100%)**, **Tablet (720px bezel frame)**, dan **Mobile (375px phone bezel)**.
6. **Desain Glassmorphism Responsif:**
   - Toolbar flat minimalis dengan garis pemisah tipis dan scrolling sentuh horizontal ramah perangkat seluler (mobile).
   - Full-body theme toggle (Light / Dark Mode).
